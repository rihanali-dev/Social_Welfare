# AshaCare Foundation - Social Welfare Web Application

AshaCare Foundation is a dedicated social welfare web platform designed to bridge the gap between volunteers, donors, and underprivileged communities. The platform streamlines charity operations, donation tracking, volunteer registrations, and community outreach campaigns.

## 🚀 Key Features

*   **Responsive Landing Page:** Clean and modern UI/UX highlighting the organization's mission, vision, and active welfare drives.
*   **Donation Portal:** Dedicated section for contributors to support causes securely and view impact metrics.
*   **Volunteer Registration:** Easy-to-use sign-up forms for individuals looking to participate in upcoming community events.
*   **Events & Campaigns Showcase:** Real-time updates and details regarding medical camps, educational drives, and food distribution events.
*   **Contact & Support:** Interactive contact form and social links for direct communication.

## 🛠️ Tech Stack

*   **Markup & Styling:** HTML5, CSS3
*   **Interactivity:** JavaScript
*   **Development Tools:** Visual Studio Code, Git, GitHub
